# FigureDrawing

MVP
User wants to start a figure drawing session.
The user selects a folder of images to use as reference for drawing.
The user sets a timer for each image, and the total number of images to be displayed.
App lets you select a folder of images. The app randomly selects an image from the folder and displays it on screen.
While displaying the image, the app shows a countdown timer for the user to draw the figure.
The user can choose to skip the current image and move to the next one. If they do, it does not count against the total number of images to be displayed for the session.
The user can choose to end the session at any time, and the app will display a summary of the session, including the total number of images displayed and the total time spent drawing.
If the user has a fold phone, the app should display well at both resolutions
The folder the user picked is remembered between launches: the app reopens on the same library, and the folder picker starts where they left off.
